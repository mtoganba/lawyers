# SAQ — Юридическая экспертиза

Рабочий макет раздела правового обеспечения для юридической экспертизы аудиторских документов.

Целевой репозиторий: https://github.com/mtoganba/lawyers. В других репозиториях этого проекта изменения не допускаются.

## Что реализовано

- Реестр со статусами, поиском, фильтрами и выгрузкой CSV.
- «Юридическая экспертиза 2» — основной этап; «Юридическая экспертиза 3» — заключительный этап.
- Назначение исполнителя и карточка комплекта документов.
- Предлагаемые проверочные листы с выбором направлений: бюджетное законодательство, бухгалтерский учёт.
- Ответы «Соответствует», «Есть замечания», «Не применимо», «Не проверено».
- Замечания с привязкой к документу, пункту, норме НПА и рекомендуемому исправлению.
- Проверка полноты заполнения перед завершением или передачей на доработку.
- Тестовая повторная передача с сохранением прежних документов и оценок.
- Электронная форма юридического заключения в блоке результата: просмотр, скачивание DOCX и печать.
- Локальные приложения и текстовая выгрузка замечаний.
- История действий и сохранение в localStorage браузера.
- Адаптивная компоновка для узких экранов.

## Ограничения макета

ВГА не подключён: документы и передача на доработку демонстрационные. Назначение доступно в макете без разграничения ролей. Общего серверного хранилища и многопользовательской работы нет. Файлы и черновики сохраняются только в браузере. Даты сроков тестовые, нормативные сроки автоматически не рассчитываются. Критерии и процесс требуют согласования с правовым подразделением.

Для результата используется рабочий шаблон юридического заключения. Просмотр и DOCX формируются из одной модели данных карточки. Это не утверждённая нормативная форма и не подписанный документ. Электронное подписание не реализовано.

## Запуск

Статические файлы в корне репозитория образуют готовый сайт без сборки. Для работы печатных форм нужны также `print-forms.js` и включённая библиотека `docx-9.6.1.js`. Для локального просмотра:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Не открывайте HTML как `file://`: браузеру требуется HTTP для загрузки ES-модулей.

Проверки основной логики:

```sh
npm test
```

Для формирования Word используется включённая в репозиторий библиотека docx 9.6.1 (MIT), лицензия — `DOCX-LICENSE.txt`. Подключение к внешним сервисам для создания документа не требуется.

Для GitHub Pages можно опубликовать корень ветки `main` этого же репозитория. Отдельный репозиторий для размещения создавать не нужно.
